# Gem「学校マネジメント相談室」使い方マニュアル

## 0. まず3分だけ使ってみる

このマニュアルを全部読む前に、まず1回だけ相談してみましょう。

最初から、きれいな文章にする必要はありません。状況、困っていること、迷っていることをそのまま入れて大丈夫です。

### まず試すならこの3つ

#### 校内の相談を整理したいとき

```
学校マネジメントの相談です。

状況：
学年会で決めたことが、職員会議に上がる前に何度も差し戻されています。

困っていること：
誰がどこまで決めてよいのかが曖昧で、担当者の負担が増えています。

お願い：
事実・困り感・不明点を分けて、学校として何を決めれば前に進むかを整理してください。
```

#### 生徒指導や児童理解で迷っているとき

```
生徒指導の相談です。

状況：
休み時間に友達とのトラブルがあり、複数の児童の言い分が違っています。

分かっていること：
- けがはありません
- 担任がそれぞれから話を聞きました
- 保護者連絡をするか迷っています

お願い：
事実・訴え・不明点・リスクを分け、今日中に確認することを整理してください。
```

#### 教務や行事の調整で困っているとき

```
教務運営の相談です。

状況：
行事が重なり、授業時数と職員の負担が厳しくなっています。

決まっていること：
- 6月に校外学習があります
- 研究授業も同じ週に予定されています
- 学年から負担が大きいという声があります

お願い：
MustとOptionを分け、調整できることと確認が必要なことを整理してください。
```

### 最初のゴール

最初から完璧な解決策を出す必要はありません。

まずは、次のどれかができれば成功です。

- 何が事実で、何が見立てか分かった
- いま決めるべき一点が見えた
- 誰と共有すべきかが分かった
- 管理職、学年、分掌、教務などの動線が見えた
- すぐ動くことと、確認してから動くことが分かれた

このGemは、答えを急いで増やす道具ではありません。

相談をほどき、学校として何を決めれば前に進むかを見つけるための相談室です。

## 1. このGemでできること

「学校マネジメント相談室」は、学校運営に関する相談を整理し、次の判断につなげるためのGemです。

たとえば、次のような相談に使えます。

- 学年、分掌、会議、校内体制の整理
- 職員の負担、役割分担、情報共有の見直し
- 生徒指導、児童理解、保護者対応の初期整理
- 事故、けが、ヒヤリハット、安全管理の初動整理
- 教育課程、年間計画、行事、週時程、時数の調整
- 校内研究、研究主任、研究係、たい焼き型研究の進め方
- 会議資料、共有メモ、保護者連絡文、事故記録のたたき台

このGemの特徴は、すぐに施策や計画表を作るのではなく、先に「何を決めれば前に進むか」を整理することです。

そのため、学校運営で起きやすい次のような失敗を減らせます。

- 困り感を、そのまま解決策にしてしまう
- 人物評価や印象で話が進んでしまう
- MustとOptionが混ざり、何を動かせるのか分からなくなる
- すぐ行動リストを増やし、職員の負担がさらに増える
- 安全や生徒指導上のリスクを、通常相談として扱ってしまう
- 会議で何を決めるのかが曖昧なまま進む

## 2. はじめに知っておくこと

このGemでは、利用者が「生徒指導Mを使って」「教務運営Mを使って」のように指定する必要はありません。

ふつうに、相談したいことをそのまま入れれば大丈夫です。

例：

```
学年会で決めた取り組みが、なかなか校内で共有されません。
どこが詰まっているのか整理してください。
```

```
事故後の保護者連絡文を作る前に、事実・対応・未確認事項を分けてください。
```

Gemの中では、入口役のベースが相談内容を見て、必要な知識を参照します。

利用者が意識するのは、「何を相談したいか」「何に困っているか」「分かっている事実は何か」だけで十分です。

## 3. 基本の使い方

### まずは、相談をそのまま書く

最初から整理された相談文を書く必要はありません。

特に初心者のうちは、次の一文を入れるのがおすすめです。

```
うまく整理できていないかもしれません。
事実・困り感・不明点を分け、学校として何を決めれば前に進むかを整理してください。
```

この一文を入れておくと、Gemがいきなり解決策を出すのではなく、相談をほどくところから始めやすくなります。

### 入れるとよい情報

| 入れるとよい情報 | 例 |
|---|---|
| 何の相談か | 学年運営、生徒指導、安全管理、教務、研究 |
| いま起きていること | いつ、どこで、誰に関係することか |
| 困っていること | 負担、迷い、共有不足、判断の曖昧さ |
| すでに決まっていること | 日程、担当、会議、管理職確認の有無 |
| 不明なこと | 事実関係、制度、関係者の意向、期限 |

### 入力例

```
学校マネジメントの相談です。

相談：
校内研究の共有タイムが、毎回報告会のようになってしまいます。

困っていること：
先生方が自分の授業の問いや子どもの姿を話す時間にならず、研究主任の準備負担も増えています。

お願い：
たい焼き型研究の考え方に沿って、共有タイムを軽くする方向を整理してください。
```

### 出力後にやること

出てきた整理や案は、そのまま学校の決定にする前に、次を確認します。

- 事実と見立てが混ざっていないか
- 学校の実際のルール、自治体ルール、管理職判断と合っているか
- 安全や生徒指導上のリスクが過小評価されていないか
- 担当者や一部職員に負担が集中していないか
- 個人情報や内部事情を出しすぎていないか
- 次に決める場が明確か

## 4. 相談の進み方

このGemは、相談をおおむね次の流れで扱います。

利用者がこの流れを暗記する必要はありません。出力を読むときの見取り図として使ってください。

| 流れ | 何をするか |
|---|---|
| 受け止め | 相談内容を短く受け止め、すぐ解決策に飛ばない |
| 切り分け | 事実、願い、困り感、解釈、不明を分ける |
| Issue固定 | 学校として何を決めれば前に進むかを1文に近づける |
| 視座補正 | 必要に応じて、学年、分掌、会議、教育課程、学校文化へ接続する |
| 方向性整理 | MustとOption、負担とリスク、停止・統合・代替を見る |
| 実行化 | 誰が、どの場で、何を決め、どう確認するかへ落とす |
| 成果物化 | 必要な場合だけ、共有メモや文書に整える |

ポイントは、最初からHowを増やさないことです。

「どうするか」の前に、「何を決めるか」を見つけると、会議や相談が短くなります。

## 5. Issueとは何か

このGemでよく出てくる `Issue` は、単なる問題点ではありません。

ここでは、「意思決定を変える一点」という意味で使います。

### Issueになりにくいもの

- 先生方の意識が低い
- 保護者対応が大変
- 行事が多すぎる
- 研究がうまく進まない
- 子どもが落ち着かない

これらは困り感として大切ですが、そのままでは何を決めるかが見えにくい状態です。

### Issueに近づけた例

| 困り感 | Issue案 |
|---|---|
| 学年会が機能していない | 学年会で決めることと職員会議に上げることを分けるか |
| 行事が多くて大変 | 今年度中に停止・統合できる行事や会議をどこまで決めるか |
| 研究が報告会になっている | 共有タイムを成果報告から子どもの姿を語る場へ戻すか |
| 保護者対応がばらつく | 事実・学校対応・今後の確認を共通の型で伝えるか |

Issueが見えると、「次の会議で何を決めるか」「誰と共有するか」「どこまでを今決めるか」が見えます。

## 6. 学校づくり・校内体制の相談

学年、分掌、会議、職員間の情報共有などの相談では、個人の性格や能力ではなく、構造として見ます。

### 使える相談例

```
校内体制の相談です。

状況：
複数の分掌から同じ時期に依頼が出て、担任の負担が重なっています。

困っていること：
どの依頼が優先なのか分からず、締切前に混乱します。

お願い：
人を責める形ではなく、情報動線と会議の持ち方として整理してください。
```

### 出してもらうとよいもの

- いま詰まっている場所
- MustとOption
- 止める、まとめる、置き換える候補
- どの会議で何を決めるか
- 共有先と確認日

### 注意

「もっと頑張る」「意識を高める」だけでは、学校の動きは変わりにくいです。

このGemには、役割、情報の流れ、会議の決め方、職員負担として整理してもらうのがおすすめです。

## 7. 生徒指導・児童理解の相談

生徒指導や児童理解では、早く結論を出すより、安全と事実確認を優先します。

このGemは、子どもを評価・断罪するためではなく、事実、不明、リスク、次の確認を分けるために使います。

### 使える相談例

```
児童理解の相談です。

状況：
授業中に離席する児童がいます。注意すると強く反発することがあります。

分かっていること：
- 離席は午前中に多いです
- けがや他害はありません
- 担任は対応に迷っています

お願い：
子どもを決めつけず、事実・不明・背景の仮説・チームで確認することを整理してください。
```

### 出力で見るポイント

- 安全リスクはあるか
- 確認できている事実は何か
- 子どもの言葉やサインは何か
- 見立ては仮説として扱われているか
- 担任一人で抱え込む形になっていないか
- 記録に残す項目があるか

### 危険が疑われる場合

自傷、自殺示唆、虐待疑い、重大ないじめ、性的被害、暴力やけががある場合は、通常の相談整理より安全側の初動を優先します。

Gemの出力は参考にしつつ、学校の危機対応ルール、管理職、関係機関への相談を優先してください。

## 8. 危機管理・安全管理の相談

事故、けが、設備不良、災害、不審者、感染症、校外活動中の危険などでは、まず危険を止めることが最優先です。

### 使える相談例

```
安全管理の相談です。

状況：
休み時間に遊具付近で児童が転倒しました。

分かっていること：
- けがの程度は軽いようですが、養護教諭が確認中です
- 同じ場所でヒヤリハットが数回ありました
- 保護者連絡と再発防止を整理したいです

お願い：
事実・未確認事項・初動・記録・再発防止を分けてください。
```

### 出してもらうとよいもの

- 今すぐすること
- 安全確認
- 管理職、養護教諭、担任、保護者への共有
- 記録に残す項目
- 個人の注意だけで終わらない再発防止

### 注意

安全管理では、原因や責任を急いで決めないことが大切です。

まず危険を止め、児童を守り、確認できた事実と未確認情報を分けます。

## 9. 教務運営・年間計画の相談

教務運営では、時数だけでなく、教育課程、行事、週時程、会議、職員負担をつなげて考えます。

### 使える相談例

```
教務運営の相談です。

状況：
短縮日課が続き、学年から授業時数と単元進度への不安が出ています。

お願い：
教育課程上のMust、学校裁量で動かせるOption、不明・確認事項、調整案を分けてください。
```

### 出力で見るポイント

- MustとOptionが分かれているか
- 制度や標準時数を根拠なしに断定していないか
- 時数だけでなく、学びの流れと職員負担を見ているか
- どの場で何を決めるかが明確か
- 停止、統合、代替の案があるか

### 注意

制度、標準時数、自治体ルールに関わることは、Gemの出力だけで確定しません。

必ず学校の資料、教育委員会の通知、管理職判断で確認してください。

## 10. たい焼き型研究マネジメントの相談

このGemには、たい焼き型校内研究を支えるための知識も入っています。

研究をきれいに管理するためではなく、先生方の問い、子どもの姿、共有の場、次の授業改善をつなぐために使います。

### 使える相談例

```
たい焼き型研究の相談です。

状況：
自己課題が、先生方にとって提出物のようになっています。

願い：
子どもの姿を見ながら、自分の授業で試したい問いに戻したいです。

お願い：
自己課題を管理表にせず、子どもの学びと教師の学びへ接続する形に整理してください。
```

### 相談できること

- 自己課題の立て方や見直し方
- 共有タイムの問い、テーマ、グルーピング
- 学びタイムを先生方の必要感から組み立てること
- 一人一公開を重い研究授業にしない工夫
- ジャーナルを提出物ではなく研究の記憶にすること
- まとめの会を成果発表ではなく学びの語り直しにすること
- CRTや全国学テなどのデータを授業改善へ接続すること
- たい焼き通信や研究係会メモの整理

### 注意

このGemは、中心発問、指導案本文、教材研究、子どもの発言分析を代行するためのものではありません。

迷ったら、研究成果物ではなく、子どもの学び、教師の学び、次の授業改善へ戻します。

## 11. 成果物を作ってもらう

相談の整理だけでなく、必要に応じて成果物のたたき台も作れます。

ただし、このGemは成果物を増やしすぎないことを大切にします。

### 作れるもの

- 会議で共有する短いメモ
- 管理職に相談するための論点整理
- 学年会や分掌会の議題案
- 保護者連絡文のたたき台
- 事故記録、ヒヤリハット記録、対応メモ
- 生徒指導の共有記録
- 研究係会メモ、たい焼き通信のたたき台

### 入力例

```
この相談内容をもとに、管理職に相談するための短いメモを作ってください。

形式：
1. 相談したいIssue
2. 確認できている事実
3. 判断が必要なこと
4. 提案する次の一手
5. 不明点

内部事情や個人評価は入れないでください。
```

### 仕上げの注意

成果物化するときも、内容や結論を勝手に変えないことが大切です。

不明点は推測で埋めず、`〔未確認〕` や `確認事項` として残します。

## 12. よく使う頼み方テンプレート

### 相談をほどいてほしい

```
次の相談を整理してください。

状況：

困っていること：

願い：

分かっている事実：

不明なこと：

お願い：
事実・願い・困り感・解釈・不明を分け、学校として何を決めれば前に進むかを1文で示してください。
```

### Issueを見つけたい

```
この相談のIssue候補を最大3つに絞ってください。

条件：
- Issueは「何を決めれば前に進むか」の形に近づける
- WhyやHowを混ぜない
- 副論点は分ける
```

### MustとOptionを分けたい

```
次の内容について、MustとOptionを分けてください。

Must：
学校として必ず守る必要があること

Option：
学校裁量で調整できること

不明：
確認しないと断定できないこと
```

### 具体プランにしたい

```
この方向性を、学校で実際に動く具体策にしてください。

入れてほしい項目：
- 何を決めるか
- どの場で決めるか
- 担当・相談先・共有先
- 動かす順序
- 期限または判断日
- 何をもって進んだと見るか
- 負担を増やさない工夫
```

### 会議メモにしたい

```
この内容を、会議で共有する短いメモにしてください。

入れてほしい項目：
1. 今日決めたいこと
2. 確認できている事実
3. 判断が必要なこと
4. 決めすぎないこと
5. 次に共有する相手
```

## 13. うまくいかないときの直し方

### 答えが大きすぎる

```
今回は大きな方針ではなく、次の会議で決める一点に絞ってください。
```

### 施策が増えすぎる

```
追加する案より先に、停止・統合・代替できることを整理してください。
```

### 人物評価に寄っている

```
人の性格や能力ではなく、役割・情報動線・会議の持ち方として整理し直してください。
```

### 不明点が多い

```
分かる範囲で仮整理し、不明点は〔未確認〕として残してください。
質問は最大3つまでにしてください。
```

### 計画が実行できなさそう

```
この計画が本当に学校で動くか、担当・決定の場・期限・職員負担の観点で点検してください。
```

### 安全リスクが気になる

```
通常の相談整理ではなく、安全側初動を優先して整理してください。
今すぐ確認すること、管理職に共有すること、記録に残すことを分けてください。
```

## 14. 個人情報・センシティブ情報の扱い

学校マネジメント相談では、個人情報やセンシティブ情報に注意します。

Gemに入力する前に、必要に応じて次のように置き換えます。

| 入力前 | 置き換え例 |
|---|---|
| 児童の氏名 | Aさん、児童A、ある児童 |
| 保護者名 | 保護者、あるご家庭 |
| 教職員名 | 担任、学年主任、担当者 |
| 学級名 | 該当学級、本学級 |
| 住所、電話番号 | 入力しない |
| 成績、健康、家庭状況 | 必要最小限にし、一般化する |

いじめ、不登校、虐待疑い、自傷、自殺示唆、性的事案、事故、けがなどは、特に共有範囲に注意します。

Gemに入れる情報は、相談整理に必要な最小限にします。

## 15. 仕上げ前チェックリスト

出力を学校内で共有したり、文書として使ったりする前に、次を確認します。

- 事実、解釈、仮説、不明が分かれている
- Issueが1文で示されている
- MustとOptionが分かれている
- 安全や生徒指導上のリスクを軽く扱っていない
- 制度、時数、報告義務、自治体ルールを根拠なしに断定していない
- 人物評価や断罪語になっていない
- 個人情報や内部事情を出しすぎていない
- 担当、相談先、共有先が明確
- どの会議や場で何を決めるかが明確
- 職員負担を増やすだけの案になっていない
- 停止、統合、代替が検討されている
- 最終判断が必要な内容は管理職や関係者に確認する

## 16. 慣れてきた人向けの裏技

### 裏技1 先に「Issueだけ」出してもらう

```
解決策はまだ出さず、Issue候補だけ最大3つにしてください。
その後、どれを主Issueにするか選びます。
```

### 裏技2 「決めること」と「決めないこと」を分ける

```
次の会議で決めることと、今回は決めないことを分けてください。
決めないことにも理由を添えてください。
```

### 裏技3 A/B/C案で比べる

```
このIssueについて、次の3案で整理してください。

A：追加負担を最小にする案
B：仕組みとして整える案
C：学校文化として育てる案

各案について、増えること・減ること・リスクを示してください。
```

### 裏技4 管理職相談用に圧縮する

```
管理職に3分で相談できる形に圧縮してください。

構成：
- Issue
- 判断が必要なこと
- こちらの仮案
- 確認したいこと
```

### 裏技5 研究相談を軽くする

```
たい焼き型研究の相談として、研究主任・研究係の仕事を増やさない方向で整理してください。
追加する前に、今ある時間・資料・ジャーナル・共有タイムを生かす案を出してください。
```

### 裏技6 保護者連絡文の前に整理する

```
保護者連絡文を作る前に、次を分けてください。

- 確認できた事実
- 学校がすでに行った対応
- まだ確認中のこと
- 保護者にお願いすること
- 伝えない方がよい内部事情
```

### 裏技7 最後に「厳しめ点検」をする

```
この整理を、学校内で共有する前に厳しめに点検してください。

観点：
- 事実と仮説の混同
- 個人情報
- 人物評価
- 安全リスク
- 実行できない計画
- 職員負担の増加
- 決定の場の曖昧さ
```

## 17. 秘技：カスタム版「学校マネジメント相談室」を作る

ここからは、管理者や慣れてきた人向けの使い方です。

Gem「学校マネジメント相談室」は、Knowledgeに入れるファイルを加えたり、外したり、学校の実情に合わせた資料を追加したりすることで、自校版に育てられます。

### 基本セット

まずは、次のファイルをKnowledgeに入れるのがおすすめです。

| ファイル | 役割 |
|---|---|
| 学校マネジメント相談室ベース | 相談室全体の入口、Issue固定、出力ルール |
| 対話発想M | 相談をほどき、事実・願い・困り感・不明を分ける |
| 学校づくりデザインM | Issueを学校として選べる方向性にする |
| 具体プランニングM | 方向性を担当・期限・決定の場へ落とす |
| 生徒指導M | 子どもの安全と尊厳を守る対応へ整理する |
| 危機管理・安全管理M | 事故、けが、安全上の危機の初動と記録 |
| 教務運営M | 教育課程、年間計画、時数、行事、職員負担の整理 |
| たい焼き型研究マネジメントM | たい焼き型校内研究の接続と軽量運営 |

### 加えると便利なKnowledge

追加すると効果が出やすいのは、次のような資料です。

- 学校の年間計画
- 校務分掌表
- 会議体の一覧
- 危機管理マニュアル
- 生徒指導・いじめ対応の校内フロー
- 保護者連絡の文例
- 事故記録、ヒヤリハット記録の様式
- 校内研究の年間計画
- たい焼きタイム、ジャーナル、研究通信の見本
- 管理職確認前のチェックリスト

ただし、児童名、保護者名、教職員名、成績、健康情報、家庭状況、住所、電話番号などの個人情報は入れません。

### 用途別のカスタム例

#### 1. 管理職・主任向け相談強化版

向いている人：

- 管理職、教務主任、研究主任、学年主任、分掌主任
- 会議や校内体制の相談が多い
- 判断の論点を短く整理したい

Knowledgeに入れるもの：

- 学校マネジメント相談室ベース
- 対話発想M
- 学校づくりデザインM
- 具体プランニングM
- 教務運営M
- 校務分掌表、会議体一覧

#### 2. 生徒指導・安全管理強化版

向いている人：

- 生徒指導、生活指導、安全担当、養護教諭との連携が多い
- 事実整理、記録、保護者連絡を安全に行いたい
- 担任一人で抱え込まない動線を作りたい

Knowledgeに入れるもの：

- 学校マネジメント相談室ベース
- 生徒指導M
- 危機管理・安全管理M
- 記録様式
- 校内対応フロー

#### 3. 教務運営強化版

向いている人：

- 年間計画、週時程、行事、時数、会議の調整が多い
- MustとOptionを分けたい
- 職員負担を見ながら学校全体を動かしたい

Knowledgeに入れるもの：

- 学校マネジメント相談室ベース
- 教務運営M
- 具体プランニングM
- 年間計画
- 週時程、行事予定、会議予定

#### 4. たい焼き型研究強化版

向いている人：

- 研究主任、研究係
- たい焼き型校内研究を軽く回したい
- 共有タイム、学びタイム、一人一公開、ジャーナルをつなげたい

Knowledgeに入れるもの：

- 学校マネジメント相談室ベース
- たい焼き型研究マネジメントM
- 具体プランニングM
- 校内研究年間計画
- たい焼き通信やジャーナルの見本

### カスタム版を作るときの注意

- 個人情報をKnowledgeに入れない
- 古い校内ルールや古い日程を入れっぱなしにしない
- 何でも相談できるGemにしようとして、目的を広げすぎない
- 安全、制度、時数、報告義務はGemだけで確定しない
- 学校としての正式判断をGemに決めさせない
- 追加資料を入れすぎて、何の相談室か分からない状態にしない

### 秘技のまとめ

カスタム版「学校マネジメント相談室」を作るコツは、次の一言です。

```
入口は一つ、Knowledgeは用途に合わせて絞る。
```

まずは基本セットで使ってみて、よく相談する内容が見えてきたら、生徒指導版、教務運営版、たい焼き型研究版のように分けて育てるのがおすすめです。
